# MentorLink — User Guide

MentorLink works in any modern browser on a computer, tablet or phone: https://mentorlink-client.vercel.app

On a phone, tap the **☰** button at the top right to open the menu.

## Getting started

1. Open the site and choose **Get Started**.
2. Pick **Student** or **Mentor**, then enter your name, email, field and a password.
3. Students go straight to their dashboard. Mentors can sign in straight away, but they only appear in Discover once an admin has verified them.

## For students

| Screen | What you can do |
|--------|-----------------|
| **Dashboard** | See how many mentors, goals in progress and unread messages you have, plus your active mentors and goal progress |
| **Discover Mentors** | Search by name, field or company; filter by field, availability and minimum rating |
| **Mentor profile** | Read a mentor's bio, skills and reviews; leave a review; request mentorship |
| **Mentorship Request** | Choose a goal type (Academic, Career, Leadership, Entrepreneurship, Personal Growth), how often you want to meet, and write a short message |
| **My Mentorships** | Active, Pending and Past tabs; message a mentor or jump to your goals |
| **My Goals** | Add a goal with milestones, tick milestones off and watch the progress ring fill up. A goal completes when every milestone is ticked |
| **Messages** | Chat with your mentors in real time |
| **Notifications** | Request updates, new messages and completed milestones, grouped into Today and Earlier; **Mark all read** |
| **Settings** | Edit your profile, notification preferences and password |

## For mentors

| Screen | What you can do |
|--------|-----------------|
| **Mentor Dashboard** | See pending requests and **Accept** or **Decline** them; follow each mentee's goal progress |
| **Messages** | Chat with your mentees in real time |
| **Notifications** | New requests and messages |
| **Settings** | Edit your profile and preferences |

## For admins

**Mentor Verification** lists mentor applications. Filter by All / Pending / Approved / Rejected, then **Approve** or **Reject**. Only approved mentors are shown to students.

## Tips

- Refreshing the page keeps you signed in.
- To see live chat, sign in as the student in one window and the mentor in a private window, then send messages between them.
- If the first load is slow, give it a moment — the server may be starting up after a quiet period.
